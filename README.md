# TerraScope Care Resilience — prototype

Clickable product prototype of TerraScope Intelligence: climate and adverse-weather
continuity intelligence for adult social care, shown on the 277 registered care homes
in Lincolnshire.

Built entirely from published data (CQC care directory, Environment Agency, Met Office,
UKHSA; Open Government Licence). It holds no personal data. Showing a provider's homes
does not mean that provider uses TerraScope. Anything a viewer enters stays in their own
browser.

The whole app is `index.html`. Replace that file to publish a new version.
